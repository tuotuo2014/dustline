# 废土回响 · Dustline

## 视频参考步态

根据用户提供的两段走路视频，四位角色共用的新步态采用约 0.81 秒的完整左右脚周期、克制的交替摆臂、前摆时自然屈肘、轻微肩胯反向转动和头部稳定。普通移动速度为 1.8 米/秒（在视频参考版本上加快约 24%），Shift 奔跑为 7.8 米/秒；动画按真实位移推进。走路有双脚同时支撑的过渡，跑步采用独立的蹬地、收腿和腾空曲线，保留坡面脚底对齐、落脚锁定、转向重心、起跳及落地缓冲。接地时保留膝盖弯曲，避免腿部接近完全伸直时突然折动。走路时每只手独立反向跟随同侧大腿的实际轨迹；不再用两腿位置差共同驱动双臂，避免姿势排序正确、运动方向却同向的问题。起步从脚位于胯下的支撑姿势进入，摆臂随移动强度渐入并在停稳后回落；手臂前后幅度围绕髋部平衡。奔跑沿用原有摆臂曲线。

视频没有完整展示脚部和奔跑，因此这是按可观察节奏与姿态重建的程序动画，并非逐帧三维动作捕捉。`tests/video_gait_regression.gd` 检查四位角色的步频、双脚支撑、腾空、关节连续性、脚底高度和反向摆臂；`tests/walk_crossbody_regression.gd` 同时检查实际膝盖和手部的前后顺序及逐帧运动方向，覆盖四人稳定行走、真实脚部锁定、起停连续性与停稳回正；`tests/reference_locomotion_preview.gd` 输出实际模型的 30 fps 对照序列，此前 1.45 米/秒版本的对照成片为 `previews/reference-walk-run.mp4`；上一版交叉摆臂预览为 `previews/crossbody-walk-run.mp4`；当前实际地图的前、侧、后视角验证片为 `previews/ingame-walk-corrected.mp4`，由 `tests/ingame_walk_capture.gd` 使用真实物理帧、角色控制器与地形采样生成。

坡面法线改为归一化线性插值，避免近似平行法线触发 Godot 的旋转轴未归一化错误。当前启动界面及组队大厅脚本已通过实际启动和角色进入测试。旧运行实例需要停止后重新按 F5，才能加载这些修改。

## 独立地图

断桥荒原、锈海工业区、沙埋旧都、暮火聚落分别位于 `maps/` 下的四个独立场景。进入行动只实例化选中的地图，切换目的地会释放旧地图及旧行动中的碰撞、物资、狼兽和撤离标记。每张地图都在自己的局部坐标中生成，具有独立地形、边界、光照、营地、三座信标和一个撤离点；地图之间不再通过大世界道路连接。

断桥荒原保留 420×420 米的探索范围及其五处聚落；其他三张地图各有 210×210 米的探索范围。人物与狼兽使用当前地图的边界。资产、升级、装备和角色选择继续共享，任务与随身物资按每次行动重新生成。暂停时浏览其他目的地后点击“继续”仍返回原行动，“重新开始”重开当前地图；选择目的地并点击模式按钮才进入另一张地图。

`tests/reference_regions_regression.gd` 检查实际菜单切换、旧地图释放、地图独立性、出生点、物资可达性、任务结算以及继续/重开的行为。`tests/independent_maps_preview.gd` 分别渲染四张地图的实际游戏画面。

## 新手教程

首次进入行动会自动开启十二步新手引导：欢迎、移动、拖动视角、奔跑、跳跃、拾取物资、角色技能、治疗、驱兽、避难棚、本轮任务、撤离与资产结算。每步配有可缩放的操作示意图、三条具体说明、按键提示和完成反馈。操作练习根据真实动作自动推进；治疗、驱兽和建造等说明页不要求消耗物资。

金色箭头与指示环标记实际物资，屏幕箭头随镜头更新；目标在身后或画面外时会提示转向。技能、生命条和物资数量会在相应步骤被高亮，任务与撤离箭头指向当前独立地图的实际信标及出口。箭头只指方向，不代替寻路，遇到障碍需要绕行。教程卡片占用原任务面板的位置，结束后恢复正常界面；图示使用轻量二维矢量图，不新增三维预览视口。

练习期间任务计时、狼群行动和沙暴伤害暂停，角色可以自由移动。拾取和技能仍使用真实游戏规则，教程不额外赠送资产或装备。完成或跳过后恢复正常行动；暂停菜单会保留当前教学进度。从菜单点击 **新手教程 / 重新学习** 可以随时重学，已有行动的物资和任务进度保留。如果本轮物资已经拾完，拾取教学会改为说明并允许继续。

完成或跳过的偏好单独保存在资产存档旁的 `.tutorial.cfg` 文件，下次进入不再自动弹出。未完成就重开行动会从第一步重新引导。

## 三种模式

开始行动前可以从角色卡选择四名可玩幸存者：荒原·行者、赤砂·林烬、夜巡·零鸦、铸火·老莫。选择会保留到重开和切换模式，四人共享完整的移动、奔跑、跳跃和镜头控制。

- **探索收集**：搜集零件，修复 3 座无线电信标，每座需要 2 个零件；随后回营地按 E 完成。
- **限时撤离**：180 秒内携带至少 6 个零件，到北侧撤离点按 E。
- **废土生存**：坚持 120 秒并修复任意 2 座信标，再回营地按 E。平静 30 秒、沙暴 15 秒，循环变化；暴露在沙暴中会失血。

## 战利品、资产与营地商店

地图新增 **40 处贵重物品**，沿废墟和五个新区的补给路线分布。走近自动拾取：金币袋 **15 G**、古董腕表 **55 G**、军用数据芯 **100 G**、封存金锭 **180 G**。行者的 C 技能也能标记这些物资。

界面显示「营地资产」和「随身战利品」。背包内的物品必须在**完成当前模式目标后成功撤离 / 返回营地交付**，才会兑换成永久资产。失败、放弃和重开会丢失当前背包；营地资产和角色等级保留。**角色死亡（生命归零）会清空全部已购枪械、护甲、医疗组件以及随身与库存弹药，必须重新购买；成功完成一局保留装备。** 枪械收起也不免除死亡损失。主动放弃或超时但未死亡仍保留装备并退回余弹。已存入资产自动保存，重开游戏也能继续使用。三种模式都能结算战利品，零件仍用于修复、建造和制作驱兽信号。

成功、死亡、超时和放弃都会显示结算页，列出地图与模式、行动用时、回收零件、修复信标、战利品收益或损失、营地余额、装备保留或遗失清单及保存状态。死亡页提供「返回商店 · 重新购买」和「空装再出发」。死亡交易与结算一次性保存；保存失败时阻止重新出发和购买，回营地重试，避免重复扣除或恢复死亡装备。联机继续使用独立的配发装备，小队结算显示团队战绩，不操作未带入联机的营地装备。

## 游戏界面与全图雷达

左上角是科技风 2D 全图雷达，右上角是任务与撤离信息，生命、共享物资、技能和行动状态位于底部。键位说明、交互提示和即时消息移到顶部。教程会避让雷达及底部状态栏。

雷达北向上，展示当前独立地图的建筑、道路和沙丘等高线。全部狼兽都显示专用红色狼头图标，不受距离限制；联机队友用青色圆形图标表示，白色箭头是自己，扇区表示镜头方向。密集生物图标会错开放置，并以连线指向实际位置，避免队友或狼群标记互相遮挡。物资仍只标记附近可拾取项；信标、营地及撤离点全图可见。

地形在换地图时缓存，标记限频刷新；只绘制 2D 图形，不增加第二个 3D 摄像机。

## 组队联机（最多 4 人）

1. 所有人运行相同版本的游戏，先选好角色，再打开菜单中的「真人联机」。若正在单人行动，请先完成或放弃该行动。
2. 房主填写昵称，点击「创建房间」。默认 UDP 端口为 `24567`；房间会显示本机 IP。
3. 同一 Wi-Fi / 局域网的队友可在「附近的真人房间」中选中房间并加入。也可以由房主点击「复制邀请地址」，朋友将 `dustline://地址:端口` 粘贴到加入栏，填写昵称后加入；普通 IP / 域名加端口仍可使用。同机测试可用 `127.0.0.1`。多个网卡时，房主选择和朋友同一网络的地址。
4. 大厅显示实际连接的玩家及空余席位，至少两位真人连接后才能出发。房主选择地图和模式；变更设置会取消队友准备状态。所有人点击「我已准备」后，房主点击「房主开始行动」，等待所有队员加载完成后共同出发。
5. 队伍共享零件、医疗包、驱兽弹、信标进度和战利品；各自拥有生命、技能冷却及 30 发驱狼弹。各角色技能、枪械、搭棚、治疗和驱兽仍使用原来的按键。
6. 狼兽会追击附近仍可行动的队员。生命耗尽会倒下，队友在 3.2 米内按 E 救起，恢复 40 生命并获得短暂保护；全员倒下则失败。一名队员满足任务条件并交互，即触发全队撤离。
7. 打开菜单不会暂停联机世界。房主离开后其他玩家回到菜单；普通队友离开时移除对应角色。结算后可在组队大厅换图再次出发。

当前使用局域网 / 可达 IP 直连，没有公共匹配服务器或房间码中转。跨互联网使用时需要房主地址可达，并将所选 UDP 端口转发至房主电脑。联机战利品记录为本次小队战绩，不写入单人经济存档；离开房间后恢复原单人档案。

附近房间通过 UDP `24568` 搜索，只在大厅未连接时每两秒搜索，关闭大厅即停止；房主持续回复搜索。关闭的房间约 6.5 秒后从列表消失，行动中或满员的房间不可加入。访客 Wi-Fi 的设备隔离、防火墙或广播端口被占用可能使自动搜索不可用，此时仍可用邀请地址直连。邀请地址只包含连接地址，不是能穿透网络限制的公网房间码。

房主统一决定物资归属、信标、怪物 AI、伤害、技能和结算，客户端提交操作请求并同步自身移动。状态快照压缩后分通道发送，带轮次编号，重开时旧包不会应用到新地图。移动仍采用客户端预测，适用于熟人合作，不作为公开竞技的反作弊方案。

运行 `python3 tests/run_coop_regressions.py` 可启动两个独立进程检查实际 ENet 联机、移动、拾取、治疗、技能、射击、修复、救援和共同撤离；加 `--capacity` 检查四人满员、全员倒下、重开换图与房主断开，加 `--visual` 可生成真实联机截图。可用 `--godot` 指定 Godot 运行程序。测试使用各自独立的临时存档。`tests/minimap_regression.gd` 检查四图全生物标记及新版界面布局，带图形界面运行也会生成截图。

双进程测试现在通过真实 UDP 搜索和大厅加入按钮连接；`tests/coop_invite_regression.gd` 额外检查邀请地址解析、真实房间广播、去重、异常包过滤、行动状态、房间失效和关闭搜索。

## 验证

`tests/weapon_aim_regression.gd` 验证鼠标准星、偏离中心的实际命中、右键射击、掩体遮挡、K 键 4 倍镜、第一人称位置、退出恢复、暂停与死亡释放鼠标；带图形界面运行生成普通准星和倍镜截图。联机测试额外检查客户端右键射击的目标方向正确传到房主。

`tests/economy_profile_regression.gd` 验证死亡清装的原子保存、失败回滚、重复结算保护和重新购买；`tests/death_settlement_regression.gd` 验证真实致命伤害、装备加成失效、死亡后空装出发、商店重新购买、保存重试及成功 / 死亡结算。带图形界面运行会生成结算截图，附加 `-- --preview-only` 可仅检查并截取结算画面。

`tests/tutorial_regression.gd` 使用独立临时存档，验证真实进入按钮、移动、拖动镜头、跑跳落地、自动拾取、四角色技能、三模式撤离说明、练习保护、暂停恢复、完成与跳过保存、重学和物资耗尽的处理。`tests/tutorial_preview.gd` 生成常规及紧凑窗口的实际游戏截图。运行旧的玩法回归测试时额外设置 `DUSTLINE_TUTORIAL_DISABLED=1`，让其直接验证正式行动规则。

`tests/economy_profile_regression.gd` 检查持久化资产、结算幂等、购买升级、有限弹药、存档损坏和保存失败回滚；`tests/economy_regression.gd` 检查真实营地按钮、V 键、三种模式入账、失败/重开、角色升级和装备实效；`tests/firearm_regression.gd` 检查四人持枪、视线阻挡、射程、冷却、击退和狼群逃跑。资产测试使用独立临时存档。运行其余主场景回归测试时，请设置 `DUSTLINE_PROFILE_PATH` 为独立临时文件，避免影响自己的游戏资产。

`tests/character_skills_regression.gd` 检查 C 键和界面按钮、物资感知、眩晕和击退、视线阻挡、突进碰撞与躲避、无人机跟随和治疗上限、暂停/换人/重开的技能生命周期。

新增 `tests/character_selection_regression.gd` 验证真实选择按钮、不同脸部几何、预览和场内角色一致、跑跳及继续/重开；`tests/expanded_world_regression.gd` 验证扩大范围后的地形碰撞、建筑碰撞、可通行补给点和静态合批。


`tests/character_regression.gd`、`tests/locomotion_regression.gd` 检查角色及移动；`tests/character_motion_regression.gd` 检查眨眼、手指、支撑脚滑移、鞋底接地、转弯和跳跃落地；`tests/gameplay_regression.gd` 检查真实按钮点击、模式目标、暂停、重开、资源和生存规则；`tests/mutant_attack_regression.gd` 检查追击、攻击、命中、脱身、庇护和死亡结算；`tests/mutant_visual_regression.gd` 检查怪兽骨架和动画。
