# 性能调整

默认继续使用 Forward+、夕阳阴影、环境遮蔽、体积雾和辉光。调整重在控制不可见细节及高分辨率屏幕的成本：

- 全屏 3D 渲染限制在 1920×1080 范围内，按屏幕比例缩放，使用 FSR 放大；界面文字保持输出分辨率。较小窗口按原生分辨率绘制，调整窗口后自动重新计算。
- 方向光阴影从 8192 调为 4096，阴影距离从 210 米调为 100 米，抗锯齿由 4 倍调为 2 倍。保留 SSAO，关闭额外的 SSIL，降低体积雾采样成本。
- 世界仍按材质和空间区块合批，小零件按尺寸分成 55 米、95 米的显示范围，并取消其独立投影。建筑、道路、地形和所有碰撞保留。
- 拾取物近处保留模型，远处不再绘制细节；拾取判定、资源数量、标记和任务逻辑不变。
- 狼兽近处保留六层毛发，远处使用较少的毛发层；为阴影提供实体轮廓，避免重复绘制毛发细节。

## 检查方式

`tests/render_budget_regression.gd` 检查从 720p 到 4K 及竖屏的分辨率限制、界面尺寸与缩回窗口后的清晰度恢复。

`tests/performance_benchmark.gd` 使用独立临时存档，按固定的 1440×900 输出采样三个区域，记录帧耗时、P95、绘制调用和图元数量，并保存实际画面至 `previews/performance-gameplay.png`。测试强制绘制离屏视口，防止窗口被遮挡时把未渲染的空帧算作性能。Metal 返回的 GPU 计时可能为零，此时不能作为 GPU 耗时使用。

这台机器还有其他运行中的游戏和图形应用，后台负载变化较大，因此不把本次帧率当作稳定帧率保证。相同输出尺寸、断桥采样位置的绘制调用由约 2673 降至 1627，提交图元由约 889 万降至 524 万；全屏像素数限制的收益不包含在这组 1440×900 数据中。

为避免另一项地图扩建任务写入中间状态干扰测试，移动与玩法回归也在完整的临时项目副本上运行。运行主场景测试时应设置独立的 `DUSTLINE_PROFILE_PATH`，避免影响玩家资产。

正在运行的旧游戏不会自动获得项目渲染设置变更；结束当前运行并重新启动后生效。
