# 废土回响 · 独立手机版

这个目录是从原版复制出来的独立手机版。游戏源项目在 `project/`，原版仍在上一级目录；手机版有独立的存档目录 `DustlineMobile`。修改手机版不会同步修改原版。

## 手机上怎么玩

### 安卓安装包

把 `builds/android/Dustline-Mobile.apk` 传到安卓手机，点击安装，再从桌面打开。首次安装时，按安卓系统提示允许当前文件来源安装应用。

这是 ARM64 测试安装包，未上架商店；使用 Godot Mobile 渲染器。旧机型如果不能运行原生版本，可以尝试下面的浏览器入口。尚未在真实安卓手机上测试性能。

### 安卓和 iPhone 浏览器入口

1. 在这台电脑双击 `打开手机版.command`。
2. 等待窗口显示 **https://…trycloudflare.com/** 地址。最新入口也保存在 `当前手机网址.txt`。
3. 在手机浏览器打开这个 HTTPS 地址。iPhone 使用 Safari，安卓使用 Chrome。
4. 横过手机，等待下载进度和场景准备完成，再进入游戏。

手机不必与电脑连接同一个 Wi-Fi，但都需要联网。电脑和启动窗口保持开启。免费临时网址在下次启动时可能变化，以窗口及 `当前手机网址.txt` 中的新地址为准。获得链接的人可以打开此游戏；入口只提供编译后的游戏资源。

**原先的 `http://192.168.1.125:8077/` 不能直接运行游戏。** Godot 需要浏览器安全连接，只有电脑本机的 `http://localhost:8077/` 是例外。现在旧局域网入口会自动转到正在运行的 HTTPS 地址；入口尚未准备好时会显示中文提示并重试。

第一次下载约 32 MB 压缩资源，之后还要生成场景，请等待画面出现。已在桌面 Chrome 中检查安全连接、资源加载和触屏进入；具体手机的性能仍需真机验证。

### 真人联机：两到四人一起玩

所有玩家打开同一个最新 HTTPS 游戏网址，进入「真人联机」。一位玩家创建房间，把六位房间码告诉朋友；朋友输入房间码加入。选好角色后每个人点「准备」，房主开始行动。

也可以复制完整邀请链接：朋友打开链接后，房间码会自动填好；或直接在加入栏粘贴链接。安卓安装版进入「真人联机」后打开「互联网组队」，填入相同的 HTTPS 游戏网址，再创建房间或输入房间码加入。加入时若直接粘贴邀请链接，空白的网址栏会自动补齐。关闭「互联网组队」则使用同一 Wi-Fi 的附近房间。

房间只显示实际连接的玩家，没有机器人替身。大家可以一起探索、拾取、战斗、救援和撤离。队伍最少两人、最多四人，已出发的房间暂不接受新玩家；房主离开会关闭房间。手机无需连接同一个 Wi-Fi，但每位玩家都需要网络连接。浏览器联机通过同一个 HTTPS 入口连接独立的 WebSocket 中继。

房主请保持游戏在前台，电脑及启动窗口也要保持运行。某位玩家断开会从队伍中移除，服务不会自动补上假玩家。

### iPhone 原生版

项目已提供 iOS 导出配置和官方模板。当前电脑没有完整 Xcode，也没有提供 Apple 签名团队信息，因此**尚未生成可安装的 IPA**。可先使用手机浏览器版。后续用 Xcode、自己的 Apple 签名信息构建，步骤见 `BUILDING.md`。

## 触屏操作

| 操作 | 位置 / 方法 |
| --- | --- |
| 移动 | 左下摇杆，轻推慢走，推到底正常走路 |
| 转动镜头 | 右侧空白处滑动，可与移动同时操作 |
| 奔跑 | 点「奔跑」开启，再点关闭 |
| 跳跃 | 点「跳跃」，可边跑边跳 |
| 拾取 / 修复 / 撤离 / 救援 | 走近目标后点「交互」；部分物资自动拾取 |
| 角色技能 | 点「技能」 |
| 开火 | 买枪并装备后点「开火」，可按住连续射击 |
| 倍镜 | 点「瞄准」，滑动右侧调整准星，再点退出 |
| 生存工具 | 「治疗」「驱赶」「搭棚」 |
| 暂停 | 右上「菜单」；安卓返回键也可打开菜单 |

暂停、离开应用和重新开始会清空按住的动作，避免角色一直跑。单人游戏进入后台会暂停。商店、角色选择、地图选择和新手教程均可触屏操作；长菜单可以滑动。

## 手机适配

- 横屏界面，照顾手机安全区域；界面顶部显示生命、任务与雷达，底部留给双手操作。
- 保留原有地图、人物、走跑跳动作、技能、搜集、撤离与成长系统。
- 3D 画面最高内部渲染尺寸 1280 × 720，界面跟随屏幕尺寸。
- 使用手机渲染设置、双级方向光阴影和普通沙尘雾；降低远处碎屑和地面网格开销。
- 手机与原版、安装版与浏览器版的存档互相独立，不会自动同步。

## 文件位置

- `project/project.godot`：用 Godot 4.7.2 导入并编辑手机版。
- `builds/android/Dustline-Mobile.apk`：安卓测试安装包。
- `builds/web/index.html`：手机网页文件，需通过上面的启动器访问，不能直接双击 HTML 玩。
- `project/previews/`：真实引擎生成的手机尺寸画面。
- `build_mobile.sh`：重新导出安装包和网页。
- `BUILDING.md`：工具来源、打包说明和验证记录。

在电脑上用 Godot 打开手机版时，也保留了键盘和鼠标操作，便于调试。
