# Entry artwork

`wasteland-entry.png` is copied from the project’s actual Godot scene render, `previews/reference-dusk-street.png`. It is local project artwork, not an AI-generated image or an external download. `wasteland_menu.gdshader` applies an ochre print treatment, film grain and slow dust movement. `wasteland_portrait.gdshader` uses the same scene behind the live character preview.
